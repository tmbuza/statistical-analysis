# Example data

`example/independent-groups.csv` contains 48 synthetic participants, 24 per group. Scores are illustrative unitless values, not observations from people. Created with Python's standard random generator, seed 20261103, normal means 50 and 55 and standard deviations 7 and 10. One row represents one independent participant; no pairing is implied.

Columns: `sample_id` (unique identifier), `group` (A or B), `score` (numerical outcome).

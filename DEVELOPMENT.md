# Chapter completion checklist

- Define the question, sampling unit, design, and estimand.
- State hypotheses and assumptions accurately.
- Supply documented example inputs and runnable scripts.
- Validate numerical output and direction of effects.
- Include appropriate effect sizes and uncertainty.
- Explain limitations and alternatives without automatic test-selection rules.
- Add checked primary references and software versions.
- Render and inspect desktop and mobile navigation.

Do not publish placeholder chapters as finished guidance.

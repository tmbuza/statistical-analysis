# Scripts

- `bash/`: setup, readiness checks, and rendering.
- `python/`: Python analyses in a project-specific `.venv`.
- `R/`: R analyses, initially using base R only.

Prefix scripts with chapter numbers. Use the language best suited to the task; duplicate implementations only when comparison helps learning. Keep computed results in `results/`. Record dependency versions when validating each chapter. Add an `renv.lock` only after initializing and validating the R project, not as a guessed lockfile.
